# Find more skills and instructions

Start with the [selection guide](selection-guide.md) and the existing catalog. If there is a genuine gap, use the sources below to discover candidates; this catalog remains a curated starting point rather than a mirror.

| Source | Best for | Pay attention to |
| --- | --- | --- |
| [skills.sh and find-skills](../catalog/tools/context-and-retrieval/skills-sh.md) | Search public skills by outcome or topic and find the original repository. | The directory, CLI and find-skills skill are different components. Popularity and audit labels are leads, not proof. |
| [Awesome GitHub Copilot](../catalog/skills/development/awesome-copilot.md) | Browse community-contributed skills, instructions, agents and other resources through focused indexes. | Copilot instructions and Agent Skills have different triggers and portability; inspect the exact artifact and harness. |
| [Research shortlist](../catalog/skills/research/starter-pack-study/README.md) | Compare candidates for security, UX, research, operations and methodologies. | Candidates are source-reviewed to differing depths and are not automatically endorsed. |

## Discovery workflow

1. State the outcome, environment, permissions and expected output. Search the catalog first.
2. Search the directory or relevant upstream index. Check for a skill that already solves the same problem before proposing an original.
3. Follow each result to its canonical owner, exact skill or instruction and focused documentation. Distinguish the listed source from forks, mirrors and similarly named projects.
4. Inspect the actual instructions and any referenced scripts, tools, network calls, data handling, licenses, installation scope and conflicting triggers. Check the target harness instead of assuming portability.
5. Compare a small number of candidates against a representative task and simpler alternatives. Record source-review status, requirements, meaningful differences and uncertainty. A listing, popularity count or automated audit is not runtime or security acceptance.
6. When adding a catalog entry, link upstream and use the [entry template](../templates/catalog-entry.md). Adopt a reviewed release or pin a commit in the consuming project if reproducibility matters.

Discovery alone does not install a skill, modify an agent or grant permission to run a candidate's instructions.
