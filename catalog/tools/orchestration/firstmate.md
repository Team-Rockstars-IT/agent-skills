## Purpose and output

## Use or skip

Use for sustained work with demonstrated coordination needs. Skip for bounded single-agent tasks.

## Requirements and tradeoffs

Supported primary harness, Git, authenticated GitHub CLI and backend; tmux is reference default. Validate backend and authority; coordination adds operational costs. Token and cost impact is unmeasured here.
