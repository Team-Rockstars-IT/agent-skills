## Purpose and output

GitHub hosts a community-contributed collection of skills, instructions, agents and other resources. Its indexes and website help readers locate a relevant example or reusable component.

## Use or skip

Use for a specific need such as a language-specific instruction or an agent skill. Skip wholesale adoption: choose individual resources and check for overlap with existing repository guidance. GitHub notes that customizations come from third-party developers and asks readers to inspect them.

## Requirements and tradeoffs

The collection primarily targets GitHub Copilot. Skills, instructions, prompts, agents, hooks and plugins are different artifact types; syntax, discovery, activation and permissions are harness-specific. A Copilot instruction is not automatically an Agent Skills package and its portability to another harness is unverified. Check each resource for dependencies, scripts, data handling and side effects; token and cost impact are unmeasured.

## Obtain and maintain

Browse the [skills](https://github.com/github/awesome-copilot/blob/main/docs/README.skills.md) or [instructions](https://github.com/github/awesome-copilot/blob/main/docs/README.instructions.md) index. Review the exact item and its provenance and terms, then follow current upstream guidance if adopting it. Pin a reviewed version in the consuming project when appropriate.
