# Team Rockstars Agent Skills

A recipe book for agentic work, with a domain- and programming-language-neutral
core. Start with the result you need; load specialist context only when it fits.

## Ask your agent

```text
Read AGENTS.md in this repository. I want to [goal].
Recommend what I need and give me one first step.
```

Start with your existing agent and tools. Add something only for a concrete gap.

## Pick a task

| I want to… | Recipe |
| --- | --- |
| Clarify an outcome and its boundaries | [Clarify what you need](recipes/choose-your-setup.md) |
