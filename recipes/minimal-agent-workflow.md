# Minimal agent workflow

**Outcome:** a bounded change with evidence. **Prerequisites:** repository access, instructions and authority.

1. Read relevant instructions and state observable acceptance.
2. Choose one relevant skill, such as [define-work](../define-work/SKILL.md) or [TDD](../catalog/skills/development/matt-pocock.md).
3. Implement and run appropriate deterministic checks; inspect failures.
4. Report actual results and limitations.

Optional: [Agentic Readiness Assessment](../catalog/skills/development/agentic-readiness-assessment.md) for repository assessment adds time and has documented write and probe side effects. Evidence: actual checks, diff and unmet criteria.
