# Recipes

Start with one of the four goals below, or ask your agent to read
[AGENTS.md](../AGENTS.md). The core works with briefs, documents, designs,
data or code. Tools and specialist workflows are selected for the actual task.

## Core goals

| Recipe | Use when | Output |
| --- | --- | --- |
| [Clarify what you need](choose-your-setup.md) | Outcome, boundaries or next step are unclear | A bounded task and a useful first step |
| [Research and compare](specialist-review.md) | A question needs evidence or a choice needs reasoning | Findings or a recommendation with sources and uncertainty |
| [Work in small steps](minimal-agent-workflow.md) | Creating or improving an artifact | A result checked against the intended outcome |
| [Review and deliver](evidence-driven-delivery.md) | Assessing a result or preparing a handover | Findings, check outcomes, limits and next actions |

## Specialist workflows, when needed

| Recipe | Use when | Output |
| --- | --- | --- |
| [Repository readiness](repository-readiness.md) | Onboarding a software repository or investigating agent friction | Context check or comprehensive upstream assessment |
| [Spec-driven development](spec-driven-development.md) | A larger software change needs agreed requirements before implementation | Reviewable spec; optional OpenSpec or Spec Kit workflow |
| [Session retrospective](session-retrospective.md) | Repeated friction in a coding session | Prioritized agent-environment improvements using Matt Pocock's retro |
| [Token-efficient workflow](token-efficient-workflow.md) | Investigating observed cost/context problems | Measured comparison with a baseline |
| [Orchestration selection](orchestration-selection.md) | Considering coordination of separable tasks | A justified choice with operating boundaries |

Find concrete choices by [goal, category or programming language](../docs/skill-finder.md).
Recipes show optional upstream choices with exact source links and scoped
evidence status. Read the [catalog](../catalog/README.md) for adoption details.
See [three worked prompts](../examples/README.md) for a decision, a design
review and a code change. The [portable software example](../examples/portable-project-setup/README.md)
provides a longer engineering illustration.
Contribute a recipe using the [template](../templates/recipe.md).
