# Recipes

For a quick choice, use the four task routes in the [README](../README.md)
or ask your agent to read [AGENTS.md](../AGENTS.md). This is the complete
recipe index, including workflow improvements. Each recipe lists only the
ingredients and checks needed for its output.

| Recipe | Use when | Output |
| --- | --- | --- |
| [Choose your setup](choose-your-setup.md) | Unsure which skills or tools fit | A minimal recommendation and first step |
| [Repository readiness](repository-readiness.md) | Onboarding a repository or investigating agent friction | Context check or deliberately selected comprehensive assessment |
| [Minimal agent workflow](minimal-agent-workflow.md) | Implementing a bounded change | A change with verification evidence |
| [Specialist review](specialist-review.md) | Assessing, designing or researching within a discipline | Findings, design or report with sources and limitations |
| [Evidence-driven delivery](evidence-driven-delivery.md) | Preparing a result for review | Handover tied to actual outcomes |
| [Token-efficient workflow](token-efficient-workflow.md) | Investigating observed cost/context problems | Measured comparison with a baseline |
| [Orchestration selection](orchestration-selection.md) | Considering coordination of separable tasks | A justified choice with operating boundaries |

Read the [catalog](../catalog/README.md) for ingredient details and evidence.
For an end-to-end illustration, see the
[portable fictional example](../examples/portable-project-setup/README.md).
Contribute a recipe using the [template](../templates/recipe.md).
